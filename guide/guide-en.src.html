EDUTACTILE · QUICK GUIDE

Tactile Learning Material Maker

Produce tactile diagrams a blind learner can read by touch — without knowing braille.
This guide covers only what you click and how you export. Follow it top to bottom.

Pick a template → type your numbers → export. Braille translation, line weights, margins and the minimum spacing between tactile elements are handled for you, following TGIL and BANA guidelines.

1.Getting started

Nothing to install. The whole tool is one HTML file, and it keeps working with no internet connection.

  • On the web — https://baekjunjoo.github.io/edutactile/en.html
  • As a file — download tactile-material-maker.html and double-click it. You can hand it around on a USB stick; it runs in a classroom with no network.
Use Chrome or Edge. Building and printing work in any browser, but connecting a DotPad over Bluetooth only works in Chrome and Edge. Top right of the screen switches between English UI and 한국어 UI.

2.Pick a template

Click a subject on the left and it expands. Clicking a card redraws the preview immediately. There are 22 templates across physical education, mathematics, daily living, science, language arts, document conversion and image tracing.

3.Enter your values

Use Options on the right to set the title and the template's own settings. Everything updates as you type — there is no save button.

Below that, Dimension labels holds the numbers. Change Unit (applies to all) at the top and every measurement converts at once — 78 feet becomes 23.77 m. Millimetres, centimetres, metres, feet and inches are supported, so you can work in whatever unit the country expects.

The drawing is scaled to fit the page, on purpose. A tactile diagram reduced to true scale becomes unreadable under the fingers, so the shape is fitted to the paper and the real measurements are carried by the braille dimension labels. If you change a number and the drawing stays the same size, that is correct behaviour.

4.Edit directly on the preview

Click any text on the diagram and you edit it in place — no pop-up window. Titles, dimensions and labels all behave the same way. Press Enter or click elsewhere to commit.

5.Output settings

Braille codeUEB Grade 2 (English, TGIL submissions), Nemeth (US math braille), or Korean Braille. Switching re-translates the diagram instantly.
Paper size11.5×11 in (US braille standard), A4 portrait and landscape, B4 portrait and landscape.
Print text alongside brailleWhether sighted-readable text sits next to the braille. Screen only lets a teacher who does not read braille check the work; Include in print is for a single sheet shared by a sighted adult and a braille-reading student.

Multi-page lessons

+ Add as page pushes the current diagram onto the Lesson sequence as one page. Keep changing the diagram and adding pages, then press Generate sequence to build the whole set at once. A description typed on a page is spoken aloud on the DotPad.

6.Export

SVGVector file for embossers and the Monarch. This is the normal path to a physical tactile sheet.
PDFFor paper printing, including swell (capsule) paper.
DotPad .dtmsLoads onto a DotPad device. You can prepare these without a device connected.
BRF key pageBraille text file listing the diagram's title, measurements and labels — a key page the student can read before exploring the diagram itself.
Save spec JSONSaves the current work as a file. Open spec JSON brings it back to carry on, or to hand to a colleague.

Choosing Documents in the template list adds two more exports — Word (.docx) and eBraille (.ebrl). Upload a table-format rulebook (PDF or Word) and it becomes a narrative braille reference document.

Always print at "Actual size (100%)". Printing with "Fit to page" shrinks the braille slightly and makes it unreadable by touch. This is the single most common mistake.

7.Connecting a DotPad

With a DotPad 320 you can feel the material immediately. Turn the device on, press Connect DotPad and choose it from the list. Pressing the button again mirrors the same content to another DotPad — up to five, so a whole group can follow along.

Device keys

F1 / F4Move left / right
F2 / F3Move up / down
Left pan + F1Zoom out (see the whole shape)
Right pan + F4Zoom in (back to 1:1)
Pan keys alonePrevious / next page
Braille is only readable at 1:1. Zoom out and one pin has to cover more than the 2.34 mm braille dot spacing, so dots merge into a single pin. The screen shows a ⚠ braille unreadable warning when this happens — use zoom-out for orientation only, then return to 1:1 to read.

8.If something goes wrong

Connect DotPad does nothingCheck you opened the tool in Chrome or Edge. Safari, Firefox and embedded preview panes block Bluetooth.
The device drops outIt reconnects on its own. If it does not, power-cycle the device and press Connect DotPad again.
Changing a number does not resize the drawingExpected — the shape is fitted to the page and the real values are carried by the braille dimension labels (see section 3).
Printed braille cannot be readCheck the print scale is "Actual size (100%)".
You want to continue laterUse Save spec JSON, then Open spec JSON next time.
