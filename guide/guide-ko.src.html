촉각 교육자료 제작 도구

점자를 몰라도, 시각장애 학생이 손으로 읽을 수 있는 촉각 자료를 몇 분 안에 만드는 도구입니다.
이 문서는 화면 조작과 출력 방법만 다룹니다. 순서대로 따라 하면 됩니다.

템플릿을 고르고 → 숫자를 넣고 → 내보내면 끝입니다. 점자 번역, 선 굵기, 여백, 요소 간 최소 간격 같은 촉각 자료의 규격(TGIL·BANA 기준)은 전부 자동으로 처리됩니다.

1.시작하기

설치가 필요 없습니다. HTML 파일 하나로 전부 동작하며, 인터넷이 끊겨도 그대로 쓸 수 있습니다.

  • 웹으로 열기 — https://baekjunjoo.github.io/edutactile/
  • 파일로 쓰기 — tactile-material-maker-ko.html 파일을 받아 더블클릭하면 브라우저에서 열립니다. USB로 전달해도 되고, 오프라인 교실에서도 동작합니다.
브라우저는 Chrome 또는 Edge를 쓰세요. 만들고 인쇄하는 것은 어떤 브라우저에서도 되지만, DotPad 연결(블루투스)은 Chrome·Edge에서만 동작합니다. 화면 오른쪽 위에서 한국어 UI / English UI를 바꿀 수 있습니다.

2.템플릿 고르기

왼쪽 목록에서 분야를 누르면 아래로 펼쳐집니다. 카드를 누르는 순간 가운데 미리보기가 바뀝니다. 전부 22종이며, 체육·수학·일상생활·과학·국어·문서변환·이미지 트레이싱으로 나뉩니다.

3.값 입력하기

오른쪽 옵션에서 제목과 항목을 바꿉니다. 입력하는 즉시 미리보기에 반영되며, 저장 버튼은 없습니다.

그 아래 치수 레이블에서 숫자를 고칩니다. 맨 위 단위(전체 일괄 적용)를 바꾸면 모든 치수가 자동으로 환산됩니다 — 78피트를 미터로 바꾸면 23.77미터로 바뀝니다. 밀리미터·센티미터·미터·피트·인치를 지원하므로, 나라별 단위에 맞춰 그대로 쓰면 됩니다.

도면 크기는 용지에 맞춰 자동 조정됩니다. 손끝으로 읽는 자료는 실제 비율대로 축소하면 읽을 수 없기 때문에, 크기는 용지에 맞추고 실제 수치는 점자 치수 레이블이 전달합니다. 숫자를 바꿔도 그림 크기가 그대로인 것은 정상입니다.

4.미리보기에서 바로 고치기

미리보기의 글자를 클릭하면 그 자리에서 바로 수정됩니다. 창이 따로 뜨지 않습니다. 제목·치수·레이블 모두 같은 방식이며, Enter를 누르거나 바깥을 클릭하면 확정됩니다.

레이블과 치수 추가하기

하고 싶은 것방법
설명 붙이기레이블 추가 (도면 클릭)를 누르고, 도면에서 설명할 위치를 클릭한 뒤 문구를 입력합니다. 리드선이 자동으로 그려집니다.
길이 재기치수 추가 (두 점 클릭)를 누르고, 시작점과 끝점을 차례로 클릭합니다.

레이블 지우기레이블의 점을 더블클릭합니다. (오른쪽 목록의 ✕도 같습니다.)

5.출력 옵션

점자 코드한국 점자(국내 수업용) · UEB Grade 2(영어권·TGIL 제출용) · Nemeth(미국 수학점자) 중에서 고릅니다. 고르는 즉시 도면의 점자가 다시 번역됩니다.
용지 크기A4 가로·세로, B4 가로·세로, 11.5×11인치(미국 엠보서 표준).
묵자 병기점자 옆에 일반 글자를 함께 넣을지 정합니다. 화면에만은 점자를 모르는 선생님이 눈으로 확인하는 용도이고, 인쇄물에도 포함은 눈으로 보는 사람과 손으로 읽는 학생이 한 장을 같이 쓸 때 씁니다.

여러 쪽짜리 수업 자료

+ 페이지로 추가를 누르면 지금 도면이 레슨 시퀀스에 한 쪽으로 쌓입니다. 도면을 바꿔가며 계속 추가한 뒤 시퀀스 생성을 누르면 여러 쪽짜리 자료가 한 번에 만들어집니다. 쪽마다 설명을 적어두면 DotPad에서 음성으로 읽힙니다.

6.내보내기

SVG엠보서·Monarch용 벡터 파일. 실제 촉각 자료를 찍어낼 때 쓰는 기본 형식입니다.
PDF종이 인쇄용. 스웰페이퍼(발포지)로 뽑을 때도 이 파일을 씁니다.
DotPad .dtmsDotPad 기기로 옮겨 담는 파일. 기기를 연결하지 않아도 미리 만들어 둘 수 있습니다.
BRF점자 텍스트 파일. 도면의 제목·치수·레이블이 목록으로 정리되어, 도면을 읽기 전 예습용 "키 페이지"가 됩니다.
스펙 저장 (JSON)지금 작업 상태를 파일로 저장합니다. 스펙 불러오기로 다시 열어 이어서 작업하거나, 동료에게 넘길 수 있습니다.

문서 변환기(왼쪽 목록의 DOCUMENTS)를 고르면 내보내기에 두 가지가 더 나타납니다 — Word (.docx)와 eBraille (.ebrl). 표 형식 규정집(PDF·Word)을 올리면 점자 설명 문서로 바꿔줍니다.

인쇄할 때 배율을 반드시 "실제 크기(100%)"로 맞추세요. "용지에 맞춤"으로 인쇄하면 점자가 미세하게 줄어들어 손으로 읽을 수 없게 됩니다. 이것이 가장 흔한 실수입니다.

7.DotPad 연결하기

DotPad 320이 있으면 만든 자료를 바로 기기에 띄워 확인할 수 있습니다. 기기 전원을 켜고 DotPad 연결을 누른 뒤, 목록에서 기기를 고르면 됩니다. 버튼을 한 번 더 누르면 다른 DotPad에도 같은 화면을 보냅니다(최대 5대) — 수업에서 여러 학생이 동시에 만질 때 씁니다.

기기 키

F1 / F4위로 / 아래로 이동
F2 / F3왼쪽 / 오른쪽 이동
좌패닝 + F1축소 (전체 모양 보기)
우패닝 + F4확대 (1:1로 돌아오기)
패닝 키 단독이전 / 다음 페이지
점자는 1:1에서만 읽힙니다. 축소하면 핀 하나가 담당하는 크기가 점자 도트 간격(2.34mm)보다 커져 도트가 한 핀에 뭉칩니다. 이때는 화면에 ⚠ 점자 판독 불가 경고가 뜹니다 — 축소는 전체 형태를 훑을 때만 쓰고, 읽을 때는 1:1로 돌아오세요.

8.막혔을 때

DotPad 연결 버튼이 안 먹음Chrome이나 Edge에서 열었는지 확인하세요. Safari·Firefox와 미리보기 창에서는 블루투스가 막혀 있습니다.
연결이 끊김자동으로 다시 연결합니다. 그래도 안 되면 기기를 껐다 켜고 DotPad 연결을 다시 누르세요.
숫자를 바꿔도 그림이 그대로정상입니다. 크기는 용지에 맞춰 자동 조정되고, 실제 수치는 점자 치수 레이블이 전달합니다(3장 참고).
인쇄한 점자가 안 읽힘인쇄 배율이 "실제 크기(100%)"인지 확인하세요.
작업을 이어서 하고 싶음스펙 저장 (JSON)으로 내려받고, 다음에 스펙 불러오기로 여세요.
